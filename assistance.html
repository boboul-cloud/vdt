L'application Assistance Confidentialité Conditions

Nous écrire

Une question, un calcul qui vous semble faux, une idée pour vos séances ? Écrivez à bob.oulhen@gmail.com, en précisant si possible le modèle d'iPhone et la version d'iOS. Réponse sous quelques jours.

Premiers pas

Onglet Coureurs : créez un groupe (ou essayez le groupe d'exemple), ajoutez les élèves. Onglet Tests VMA : mesurez leur VMA. Onglet Séances : préparez une séance, lisez l'objectif de chacun, imprimez la feuille, lancez la séance. Le mode d'emploi complet est dans l'app : bouton « i », puis « Mode d'emploi ».

Questions fréquentes

Comment ajouter toute une classe d'un coup ?

Dans le groupe, menu « … » › « Coller une liste » : un nom par ligne, la VMA facultative en fin de ligne (« Léa 12,5 »). Une colonne copiée d'un tableur convient.

Comment la VMA est-elle comptée pendant un test à paliers ?

C'est la vitesse du dernier palier terminé au moment où vous touchez le nom de l'élève. Un élève arrêté pendant le premier palier n'a pas de VMA mesurée. Les élèves encore en course quand vous arrêtez le test gardent le dernier palier terminé.

J'ai touché le mauvais élève

Touchez-le de nouveau : l'app propose d'annuler son arrêt.

Que veut dire « P7 +5 m » ?

Cinq mètres après le 7e plot, la ligne de départ étant le plot 0. Avec une piste réglée (200 m, 400 m…), « 1 tour + P3 » se lit après un tour complet. Choisissez « Ligne droite » si le parcours ne boucle pas.

Je n'entends pas les bips

Montez le volume : les bips sonnent même si l'iPhone est en mode silencieux. En extérieur, une enceinte Bluetooth aide beaucoup. L'écran reste allumé pendant un test ou une séance ; gardez l'app ouverte, car les bips s'arrêtent si vous la quittez. Un appel téléphonique arrête le test ; les résultats déjà notés sont gardés.

Comment imprimer la feuille de la séance ?

Dans la séance, l'icône d'imprimante ouvre la feuille de partage : « Imprimer », ou envoyez le PDF.

Le demi-Cooper sans le chrono de l'app ?

« Saisir les distances sans chrono » : tapez la distance de chacun en mètres, la VMA s'affiche (distance ÷ 100) et s'enregistre dans le groupe.

Et les calculs de vitesse ?

Onglet Calculs : choisissez Vitesse, Distance, Temps ou Allure, remplissez les deux valeurs connues, puis « Calculer ». Le bouton CHRONO remplit le temps ; l'horloge en haut à droite rouvre les 60 derniers calculs. Les prédictions de course suivent la formule de Riegel, T₂ = T₁ × (D₂ ÷ D₁)1,06 : une estimation.

J'ai changé d'iPhone : où sont mes groupes ?

Ils sont enregistrés sur l'appareil seulement, et suivent la sauvegarde de l'iPhone (iCloud ou ordinateur) si vous l'avez activée. Lièvre n'a ni compte ni serveur où les retrouver.

Configuration requise

iPhone avec iOS 17 ou plus récent. L'application fonctionne entièrement hors connexion.
